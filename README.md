# ☕ Coffee Assistant Bot

Telegram-бот с интеграцией языковой модели для автоматизации общения с клиентами кофейни.

Бот отвечает на вопросы посетителей о меню, напитках и услугах заведения, используя предоставленную базу знаний. Для поддержания контекста диалога используется Redis, благодаря чему бот может учитывать предыдущие сообщения пользователя.

## ✨ Возможности

- **AI-консультант** — отвечает на вопросы клиентов на естественном языке.
- **База знаний кофейни** — использует информацию о заведении, переданную через системный промпт.
- **Контекст диалога** — сохраняет историю переписки пользователей в Redis.
- **Ограничение истории** — хранит последние 5 сообщений каждого пользователя.
- **Асинхронная архитектура** — использует асинхронные инструменты Python для обработки запросов.
- **Передача сложных вопросов менеджеру** — предлагает обратиться к сотруднику, если необходимой информации нет в базе знаний.

## 🏗 Архитектура

Проект разделён на несколько логических компонентов:

- **Handlers** — обработка входящих сообщений Telegram.
- **AI Service** — формирование запросов к языковой модели и обработка ответов.
- **Redis Service** — сохранение, получение и очистка истории диалогов.
- **Prompts** — системные инструкции и информация о кофейне.

### Обработка сообщения

1. Пользователь отправляет сообщение Telegram-боту.
2. Бот получает историю предыдущих сообщений пользователя из Redis.
3. Формируется запрос к языковой модели, содержащий системный промпт, историю диалога и новое сообщение.
4. Запрос отправляется в LM Studio через OpenAI-compatible API.
5. Полученный ответ и сообщение пользователя сохраняются в Redis.
6. Ответ отправляется пользователю.

## 📋 Требования

Перед запуском проекта необходимо установить:

- Python (версию, указанную в `pyproject.toml`).
- [uv](https://docs.astral.sh/uv/).
- [Docker](https://www.docker.com/).
- [LM Studio](https://lmstudio.ai/) с загруженной языковой моделью.
- Telegram Bot Token, полученный через BotFather.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <REPOSITORY_URL>
cd <PROJECT_DIRECTORY>
```

### 2. Установка зависимостей

```bash
uv sync
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token

LM_STUDIO_BASE_URL=http://localhost:1234/v1
LM_STUDIO_API_KEY=lm-studio
MODEL_NAME=your_model_name

REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=your_redis_password
REDIS_DB=0
```

Убедитесь, что файл `.env` добавлен в `.gitignore` и не попадает в репозиторий.

### 4. Запуск Redis

Redis запускается в Docker-контейнере.

Пример конфигурации `docker-compose.yml`:

```yaml
services:
  redis:
    image: redis:7-alpine
    container_name: coffee-redis
    restart: unless-stopped
    command: redis-server --requirepass ${REDIS_PASSWORD}
    ports:
      - "127.0.0.1:6379:6379"
```

Запустите контейнер:

```bash
docker compose up -d
```

### 5. Запуск языковой модели

Запустите LM Studio, загрузите необходимую модель и включите локальный сервер API.

По умолчанию LM Studio использует адрес:

```text
http://localhost:1234/v1
```

Убедитесь, что модель доступна через API.

### 6. Запуск Telegram-бота

Запустите основной файл приложения:

```bash
uv run <PATH_TO_ENTRYPOINT>
```

После успешного запуска бот будет готов принимать сообщения в Telegram.

## 🧠 Управление контекстом диалога

Для каждого пользователя создаётся отдельный Redis-ключ:

```text
chat:<telegram_user_id>
```

История хранится в виде Redis List. Каждое сообщение сериализуется в JSON и содержит два поля:

```json
{
  "role": "user",
  "content": "Есть ли у вас латте?"
}
```

Возможные значения `role`:

- `user` — сообщение пользователя.
- `assistant` — ответ языковой модели.

После добавления нового сообщения история автоматически ограничивается последними пятью сообщениями.
